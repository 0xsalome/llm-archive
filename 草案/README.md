# 草案

書きかけの記事を置く場所です。

ここに置いたMDファイルは、**サイトには公開されません**。サイト生成ツール（Astro）が記事を探しに行くのは `src/` の中だけで、このフォルダはその外にあります。置き忘れても公開事故は起きません。

## 使い方

1. 本文だけを書いたMDファイルをこのフォルダに置く（ファイル名は日本語でも構いません）
2. AIに「〇〇（タイトル）を秘密の部屋に追加して」または「〇〇を書庫に追加して」と伝える
3. AIがfrontmatter（記事の設定情報）を作り、正しい場所へ移す

frontmatterは自分で書かなくて構いません。本文を読んだAIが `docs/frontmatter-guide.md` に従って作り、移す前に内容を見せます。

## 記事の行き先

| 伝え方 | 移動先 | サイト上の場所 |
| --- | --- | --- |
| 秘密の部屋に追加して | `src/content/annex/` | 鍵を知っている人だけが読む部屋 |
| 書庫に追加して | `src/content/docs/archive/` | 通常の記事一覧 |

## gitの扱い

このフォルダの中身は `.gitignore` で除外しているため、GitHubには公開されません。書きかけの文章は手元のマシンにだけ残ります。

このREADMEだけは例外的にgitで管理しています。中身が空になってもフォルダが消えないようにするためです。
