## 1. 神楽とは何をする場なのか

語源としてよく挙げられるのが「神座（かむくら・かみくら）」、すなわち神を迎える場所という語である。この語源から見ると、神楽の本質は「見せる舞」である以前に、場を整える一連の手続きだったと考えるとつじつまが合う。場を祓い清める、神を招く、もてなす、送り出す――この一連の祭祀の中から、舞という表現形式が育っていったと考えられる[^1]。

現在の神楽にもこの構造は残っている。天岩戸や大蛇退治のような物語性の強い演目の前には、幣や笹を持って四方を清める舞が置かれることが多い。派手な演目だけを見ていると気づきにくいが、**神楽全体はおおむね「清め→招き→もてなし（神話劇）→送り」という流れで組み立てられている。**

## 2. 起源神話としての天岩戸

神楽の起源としてもっとも広く語られるのが天岩戸神話である。

須佐之男命の乱暴に怒った天照大御神が岩戸に隠れ、世界は暗闇に包まれる。八百万の神々が集まって相談し、天鈿女命が岩戸の前で神がかりして舞う。『古事記』では、天香山の小竹葉を「手草」として手に持ち、桶を踏み鳴らして激しく舞ったとされる。神々の笑い声を不思議に思った天照大御神が岩戸を少し開けると、手力男命がその手を取って外へ引き出し、光が戻った[^2]。この天鈿女命の舞が神楽の始まりだと伝えられている。

ただし、これはあくまで神話上の起源である。歴史上の神楽は、鎮魂・招魂の儀礼、巫女の神がかり、農耕儀礼、修験道、神話劇といった複数の系譜が重なり合って形成されてきたと考えられている。宮中で行われる御神楽も、平安時代になって現在につながる形式が整えられた。**神楽は単一の起源から枝分かれした芸能というより、複数の起源が合流してできた芸能である。**

## 3. 神楽の分類

神楽は大きく、宮中に伝わる**御神楽（みかぐら）**と、各地域に伝わる**里神楽（さとかぐら）**に分かれる。

里神楽はさらに、舞の形式で四つに整理できる。

| 種類 | 主な特徴 | 代表例 |
| --- | --- | --- |
| 巫女神楽 | 巫女が鈴・扇・幣を持って舞う。鎮魂・神がかりの性格を残す | 各地の巫女舞 |
| 採物神楽 | 幣・笹・剣・弓などを持つ舞と、神話を演じる神能 | 佐陀神能、備中神楽、高千穂の夜神楽、豊前神楽 |
| 湯立神楽 | 釜で湯を沸かし、湯や笹で場や人を清める | 花祭、遠山の霜月祭、豊前神楽の湯立 |
| 獅子神楽 | 獅子頭を神体・依代として舞い、祓いと祈祷を行う | 早池峰神楽、伊勢大神楽 |

古い文献では「巫女神楽・出雲流神楽・伊勢流神楽・獅子神楽」という四分類もよく使われる。ただし実際の神楽は複数の要素を併せ持つのが普通で、この分類は系譜そのものというより、特徴をつかむための目安に近い[^1]。

能の影響が特にはっきりしているのが佐陀神能である。一方、江戸の里神楽には壬生狂言の影響が明記され、伊勢大神楽では狂言より放下芸の影響が強い。早池峰神楽のように、むしろ能が完成する以前の芸態を残す神楽もある。庄内神楽についても、能の影響は確かに確認できるが、少なくとも公開資料からは「庄内神楽そのものが能から発生した」とまでは言えず、能舞から取り入れた演目と、狂言に似た役割を担う演目が神楽の中に組み込まれている、と見る方が資料に近い[^4]。

**この一覧から読み取れるのは、神楽が一つの芸能として全国に均一に広がったのではないということである。**東北では山伏修験と結びついた神楽、中部山地では湯立を中心とする神楽、中国地方では採物舞と神話劇を組み合わせた神楽、九州では夜を徹して舞う岩戸系の神楽――それぞれの地域の信仰と祭礼が、それぞれの神楽の形を決めてきた。

島根の佐陀神能は、中国地方を中心に後世の神楽へ大きな影響を与えたとされる。ただし、全国の神楽をすべて佐陀神能や出雲流の派生として説明することはできない。早池峰神楽のような山伏神楽、伊勢大神楽のような獅子神楽には、それぞれ別の系譜がある。

### 「三十三番」とは何か

「番」は個々の演目を数える単位で、プログラム上の「◯番目の演目」を指す言葉である。高千穂の夜神楽や大分の御嶽神楽が伝える「三十三番」は、一晩の神楽全体が三十三の演目で構成されていることを意味する。高千穂の夜神楽の場合、神を招く「彦舞」に始まり、天岩戸神話の一連の演目を経て、最後に神を送り返す「雲下ろし」に至るまでが三十三番で一続きになっている。観光向けの神楽殿公演では、この三十三番のうち代表的な数番（手力雄の舞、鈿女の舞、戸取の舞、御神体の舞など）だけを抜き出して通年で上演していることが多い[^14]。

## 5. 今回の神楽大会で舞われる演目の意味を読む

ここからは、神楽全体の演目を網羅するものではなく、今回の神楽大会で舞われる演目を中心に、その意味を調べてみる。演目名や内容は地域・神楽座によって異なるため、近縁の神楽に残る資料も手がかりにしている。

### 添神楽（そえかぐら）

神楽の最初に置かれる儀礼的な舞として伝わる。名称の由来や細かな所作まで説明した公開資料は少なく、「五方礼始と同じ」「神楽に添えるからこの名」といった説明も確認できない。確実に言えるのは、一連の神楽を始める位置に置かれる舞だということである。神楽全体が「まず場を整え、神を迎える」ところから始まる構造を持つことを踏まえると、この位置取り自体に意味がある。

### 笹神楽（ささかぐら）

笹を持って舞い、四方や神楽場を祓い清める。豊前神楽では手総神楽・手草神楽・手笹神楽・手房神楽など近い名称がある。笹を振る音を神の囁きとし、罪や穢れを祓うとも説明される。天岩戸神話でも、天鈿女命は小竹葉を「手草」として持って舞ったとされ[^2]、現在の笹神楽と神話上の舞に同じ採物が現れている。

### 二人手草（ふたりたぶさ）

手草とは、舞うときに手に持つ笹や榊などの採物を指す。二人手草は、その系統の舞を二人で行う形式で、二人手総・二人手房などの名称もみられる。神楽場を清め、神を迎えるための儀礼舞に近い。

### 三神（さんじん）

豊前神楽では、山の神・田や里の神・海や水の神という三柱が集まり、豊作を喜ぶ舞とされ、「餅神楽」とも呼ばれる。山・水・田・海という、暮らしを支える環境がそのまま三柱の神として舞に現れている。

### 御前・御先・駈仙（みさき）

「御前」「御先」「駈仙」など複数の漢字で表され、豊前神楽では「みさき」と読む。鬼面をつけて現れ、天孫降臨の場面では猿田彦命を表す。猿田彦は天孫の行く手に立ちはだかる異形の神だが、最終的には道案内をする役に転じる。神楽の鬼面は必ずしも悪者を意味せず、境界に立つ神、あるいは強い神威を持つ存在が鬼の姿で現れている場合がある。

### 綱御先（つなみさき）

御先の舞に、綱や蛇が加わる。豊前神楽では綱駈仙神楽・綱御先・綱切などの名称があり、鬼と幣方、蛇の掛け合いを演じる。布製や藁製の蛇を使う地域もある。八岐大蛇を連想させるが、地域によっては「大蛇退治」を別演目として伝えており、綱をそのまま八岐大蛇と結論づけることはできない。

### 米神楽（こめかぐら）

盆に米を入れて舞う豊穣祈願の神楽。盆神楽、折敷舞とも呼ばれる。米の豊作と祖先への感謝を表す一方、盆を落とさず回すといった曲芸的な所作もあり、観客を楽しませる要素も強い。神への奉納と人の娯楽が同じ舞に同居している点は、里神楽らしい特徴である。

### 天岩戸（あまのいわと）

神楽の起源説話そのものを演じる中心演目。天照大御神が岩戸に隠れ、神々が相談し、天鈿女命が舞い、手力男命が岩戸を開くまでを描く。岩戸開・戸開・岩戸前など呼び名は地域によって異なる。高千穂の夜神楽のように、この物語を複数の演目に分けて一晩がかりで演じる地域もある。

### 湯立（ゆだて）

神前に釜を置いて湯を沸かし、笹などを浸して周囲へ振りまき、人や場を祓い清める。湯立は一地方だけの演目ではなく、日本の神楽全体を貫く大きな類型の一つである。愛知の花祭や長野の遠山の霜月祭は、湯立を中心に祭り全体が構成されている。

豊前神楽にも湯立があり、斎鉾への登攀や火渡りを伴う大がかりな形が伝えられている。庄内神楽にも「湯立・荒神」があり、笹で湯を振りかけ、魔除けや疾病除けを願う伝承が残る。「昔は湯立があった」という話を聞くことがあるが、これは湯立そのものが消えたというより、地域によって上演機会が減ったことを指している可能性が高い。

### このほか全国的によく知られる主要演目

今回の大会には含まれていないものにも、各地で繰り返し舞われる代表的な神話演目がある。

- **大蛇退治（おろちたいじ）**

  須佐之男命が出雲で八岐大蛇を退治し、櫛稲田姫を救う物語。石見神楽を代表する演目として特に有名で、備中神楽や大分の神楽にも広く見られる。巨大な蛇体を使う地域では、神話劇の中でも特に演劇性の強い演目になっている。

- **国譲り（くにゆずり）**

  大国主命が治めていた葦原中国を天照大御神の側へ譲る記紀神話を題材とする。備中神楽では幕末に「大国主命の国譲りの段」が新しい様式に整えられ、現在も主要な神話劇として演じられる。

- **天孫降臨（てんそんこうりん）**

  天照大御神の孫・邇邇芸命が高天原から地上へ降る物語。途中で猿田彦命が現れて道案内をするため、御先・駈仙の演目とも深く関係する。九州の岩戸系神楽をはじめ各地で題材となっている。

- **五方礼始・四方祓などの清めの舞**

  神話劇ではないが、多くの神楽で冒頭に置かれる重要な舞である。東西南北と中央、あるいは四方を拝み、舞台を神を迎える場所へ整える。観客向けの短い公演では省略されることもあるが、神楽本来の祭祀的な性格が見えやすい演目群である。

## 6. 演目を見るときの手がかり

神の名前がわからなくても、何を持っているか、どちらを向くか、面をつけているかを見れば、舞の役割はかなり読み取れる。

| 見るもの | よく表す意味 |
| --- | --- |
| 幣・御幣 | 祓い、神への奉仕、神を迎える祭具 |
| 扇 | 礼拝や基本の舞 |
| 笹・榊 | 神の依代、祓い、露払い |
| 鈴 | 神を招く、場を清める |
| 弓・剣 | 邪を祓う、四方を鎮める、神話上の武具 |
| 鬼面 | 悪者とは限らない。猿田彦や荒神など神の姿の場合がある |
| 綱・蛇 | 蛇、霊力、対立する力。意味は地域ごとに違う |
| 米・盆 | 五穀豊穣、供物、祖先への感謝 |
| 湯・釜 | 清め、再生、無病息災 |

東西南北と中央を順に向く舞も多い。舞台の中を回っているだけに見えても、実際には四方や五方を一つずつ拝み、祭場全体を清めていることがある。演目の順番も手がかりになる。清めと神迎えの舞から始まり、次第に神話劇や華やかな舞へ移る構成を持つ神楽は多い。夜神楽では最後に神を送り、祭場を元の場所へ戻すところまでが一つの流れになっている。

## 7. 同じ舞に複数の名前がつく理由

神楽では、同じような舞が複数の名前で呼ばれる。

- 手総神楽・手草神楽・手笹神楽・笹神楽・手房神楽
- 駈仙・御先・御前
- 盆神楽・米神楽・折敷舞
- 岩戸開・戸開・岩戸前

逆に、同じ名前でも舞い方や意味が地域によって違うこともある。神楽は長く口伝で受け継がれ、近隣の神楽座同士で演目を教え合ったり、失われた舞を復元したりしてきた。一つの「全国共通版」を探すよりも、「この地域では、この名前で何を舞うのか」という個別の視点で見るほうが実態に近い。

## まとめ

全国の神楽を見渡すと、その姿はかなり幅広い。岩手には山伏修験と結びついた早池峰神楽があり、長野や愛知には煮えた湯を使う湯立神楽が残る。三重では獅子が各地を巡り、島根や岡山では採物舞と神話劇が発達した。九州では、豊前神楽や高千穂の夜神楽のように、神迎えから岩戸神話までを長い演目体系として伝える地域がある。

それでも共通して現れるものがある。まず場を清める。神を迎える。幣、笹、剣、米、湯を使って祈る。そして神話を舞い、神と人が同じ場所で時間を過ごす。**神楽は、天岩戸の物語を演じる芸能であるだけでなく、場所を神の座へ変えていく一連の技法である。**
